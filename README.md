# 大师视角 · 投资思维 Skills 合集

**中文名**：大师视角（投资大师思维操作系统 · Cursor Agent Skills）  

**英文名**：**Master Perspectives** — Distilled Investor Mindset Skills for Cursor  

本仓库收录多份 `SKILL.md`，将各位投资大师的公开方法论、决策启发式与表达习惯结构化为 Cursor 可用的 Agent Skill。内容基于著作、访谈与公开策略资料等调研整理，**仅供学习与思维实验**，不构成投资建议，亦非本人言论的复刻。

Skill 正文多标注由 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 等流程生成或延展。

---

## 如何使用

1. 将某一目录（如 `master-graham-perspective/`）整体放入 Cursor 所配置的 **Agent Skills** 路径（与官方文档中 Skill 的加载方式一致）。  
2. 对话中使用各 Skill 头部 `description` 中的触发词（人名、流派关键词等）即可倾向调用对应视角。  
3. 需要退出角色扮演时，直接说明「退出角色」「切回正常」等即可（各 Skill 内一般另有约定）。

---

## 分类说明（价值 / 成长 / 综合）

以下分类用于**快速检索风格**，边界在真实投资中有重叠；一人也可能跨类，表中按其 Skill 的**主要叙事重心**归入唯一主类。

| 标签 | 含义（简要） |
|------|----------------|
| **价值** | 安全边际、低估、现金流/资产质量、股息与财务约束、逆向或深度价值等占主导。 |
| **成长** | 盈利增长、PEG/加速成长、大型成长或积极成长选股等占主导。 |
| **综合** | GARP、价值+成长双轨、指数化与有效市场、量化多因子、长期品质复利等「混合框架」或方法论跨越传统价值/成长二分。 |
